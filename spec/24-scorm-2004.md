# Krok 24: SCORM 2004 adapter

## Cíl

Podpora SCORM 2004 (3rd/4th Edition) vedle stávajícího SCORM 1.2.

## Motivace

SCORM 2004 je novější standard s lepší podporou v moderních LMS. Přidává sequencing, objectives, scaled score. Řada enterprise LMS vyžaduje SCORM 2004.

## Klíčové rozdíly SCORM 1.2 vs 2004

| Oblast | SCORM 1.2 | SCORM 2004 |
|--------|-----------|------------|
| API objekt | `API` | `API_1484_11` |
| Inicializace | `LMSInitialize("")` | `Initialize("")` |
| Prefix | `cmi.core.*` | `cmi.*` |
| Score | `cmi.core.score.raw/max` | `cmi.score.raw/max/min/scaled` |
| Status | `cmi.core.lesson_status` | `cmi.completion_status` + `cmi.success_status` |
| Suspend data | `cmi.suspend_data` | `cmi.suspend_data` (větší limit) |
| Location | `cmi.core.lesson_location` | `cmi.location` |
| Session time | `HH:MM:SS.SS` | `P[yY][mM][dD]T[hH][nM][sS]` (ISO 8601) |
| Interactions | `cmi.interactions.*` | `cmi.interactions.*` (rozšířené) |
| Objectives | Omezené | Plná podpora `cmi.objectives.*` |

### Metody mapování

```
Initialize("")     → adapter.initialize()
Terminate("")       → adapter.terminate()
GetValue(key)       → adapter.getSuspendData(), getLocation()
SetValue(key, val)  → adapter.setSuspendData(), setScore(), setStatus(), setLocation()
Commit("")          → adapter.commit()
```

### Status mapování

SCORM 2004 má dva oddělené statusy:

```typescript
setStatus(status) {
  switch (status) {
    case 'incomplete': 
      api.SetValue('cmi.completion_status', 'incomplete')
      break
    case 'completed':
      api.SetValue('cmi.completion_status', 'completed')
      break
    case 'passed':
      api.SetValue('cmi.completion_status', 'completed')
      api.SetValue('cmi.success_status', 'passed')
      break
    case 'failed':
      api.SetValue('cmi.completion_status', 'completed')
      api.SetValue('cmi.success_status', 'failed')
      break
  }
}
```

### Session time format (ISO 8601 duration)

```typescript
function formatDuration(ms: number): string {
  const s = Math.floor(ms / 1000)
  const h = Math.floor(s / 3600)
  const m = Math.floor((s % 3600) / 60)
  const sec = s % 60
  return `PT${h}H${m}M${sec}S`
}
```

### Score: scaled

SCORM 2004 má `cmi.score.scaled` (0–1 rozsah):

```typescript
setScore(score, max) {
  api.SetValue('cmi.score.raw', String(score))
  api.SetValue('cmi.score.max', String(max))
  api.SetValue('cmi.score.min', '0')
  api.SetValue('cmi.score.scaled', String(score / max))
}
```

## Akceptační kritéria

- API_1484_11 discovery
- Správné CMI mapování (bez `core.` prefixu)
- Dva oddělené statusy (completion + success)
- ISO 8601 session time
- Scaled score (0–1)
- Fallback: SCORM 2004 → SCORM 1.2 → standalone
- Správný imsmanifest.xml pro SCORM 2004
- `createAdapter('scorm-2004')` funguje
- Unit testy
